ARCADE SIX - installable PWA
Files: index.html (all 6 games inside), manifest.webmanifest, sw.js, icons/
Game logic and rules are byte-identical to the file you sent; only visual styling changed (glass panels, glow, shine and motion effects).

INSTALL (phone): host this folder on any HTTPS site (Netlify Drop, GitHub Pages, Cloudflare Pages),
open the link in Chrome, then menu > Install app. It then runs fully offline.
ANDROID APK/AAB: upload the hosted URL to pwabuilder.com and download the Android package.
Opening index.html directly from storage works as a normal page but cannot be installed.
